# 客户演示脚本（5–10 分钟）

目标：向客户展示「照片 + 一句现场说明」如何形成可人工确认、可导出的结构化记录。演示设备使用已安装应用的手机，或手机浏览器打开部署在 Vercel 的公开 HTTPS 地址。

> Vercel Hobby 演示采用客户端辅助 HITL：确认或退回时，浏览器会带上当前整理结果，以应对 Serverless 实例内存不连续。它支持本次公开演示端到端完成，但不是生产归档或防篡改工作流。若使用模型补充字段，请配置 `STRUCTCAPTURE_LLM_*`；远程模型网关建议将 `STRUCTCAPTURE_LLM_TIMEOUT_MS` 设为 `30000`–`60000`。

## 演示前 1 分钟准备

1. 准备 3–4 张可拍摄对象：实验区域标识、设备/防护装置、物品/标签。
2. 打开应用，确认可选到「碰撞实验准备」和「家庭物品盘点」两个模板。
3. 若需演示真实 WAO，在开始前执行健康检查；不可用时保留 DevStub 路径作为可重复的降级演示：

   ```bash
   curl --fail --show-error http://198.12.81.152:8088/health
   ```

## 路径 A：碰撞实验准备（约 3–4 分钟）

**讲述开场（20 秒）**

> 现场人员不需要先填长表。选择「碰撞实验准备」后，应用会给出当前拍摄指引；每张照片再补一句人能看懂的说明。

1. 点击「碰撞实验准备」。
2. 读出顶部「当前拍摄指引」，拍摄实验区域或安全隔离线。
3. 在说明中输入：`试验区已清空，警示锥与隔离带完整。`，点击「拍照」并选择/拍摄照片。
4. 继续拍摄关键设备或防护装置，说明示例：`主设备固定完成，防护罩已锁定。`
5. 指向「本次照片」列表：

   > 即使网络暂时不可用，这些拍录会先保存在本机，现场可以继续补充。

6. 点击「完成并提交整理」，展示待人工确认的字段和照片。
7. 在结果页讲述：

   > 系统只做整理建议。请由负责人核对，确认后才允许导出 JSON 或 CSV；这避免把自动整理当成最终事实。即使 Vercel 将确认请求分配给新的 Serverless 实例，本次演示也可以完成确认或退回。

## 路径 B：家庭物品盘点（约 3–4 分钟）

**切换开场（15 秒）**

> 相同的拍录方式，换一个模板就能服务不同现场。

1. 返回首页，点击「家庭物品盘点」。
2. 拍摄一件物品及其标签/位置，说明示例：`客厅书架第二层：黑色相机包，内有备用电池。`
3. 再拍摄一件物品，说明示例：`储物柜上层：蓝色文件盒，包含房屋保险资料。`
4. 让客户查看照片列表与对应说明：

   > 说明刻意使用自然语言，现场人员不必学习复杂字段；整理时再映射到模板。

5. 点击「完成并提交整理」，展示人工确认、退回修改和导出入口。

## DevStub 降级说明（约 1 分钟，按需演示）

在未配置 `WAO_BASE_URL`、健康检查失败或 WAO 暂时不可达时，点击「完成并提交整理」仍会展示 DevStub 生成的待确认结果。

> 这是为了让现场拍录不中断，不代表数据已发送到 WAO。演示结束时应明确说明：DevStub 结果仍需人工确认；当前版本的会话 API 是演示用内存存储，不能当作生产归档。

## 收尾（20 秒）

> 我们把现场拍录、自动整理和人工确认分开：先快速留下证据，再由人对结构化结果负责。手机安装、离线注意事项和部署检查都在 `docs/vercel-hobby-deploy.md`。
